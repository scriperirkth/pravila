ОФОРМЛЕНИЕ BSL
Рефакторинг в пределах задачи, без декоративных методов и несвязанной логики.
Вложенность — табуляцией. После запятой — один пробел.
Простые присваивания, вызовы, короткие условия до Тогда, конкатенация и заголовки — в одну строку.
Правую часть после = не переносить; короткий вызов после скобки не разрывать.
Длинное имя не причина переноса. Переносить длинные выражения, сложные условия, запросы, громоздкие списки.
Тело условия с новой строки; КонецЕсли; отдельно.
Между методами одна пустая строка; между директивой и заголовком — без пустой строки.
Разделы: //!Название раздела↓
#Вставка, #КонецВставки, #Удаление, #КонецУдаления автоматически не добавлять; существующие без указания не удалять.
В начале новой доработки:
//SCR "Лаборатория С {Текущая дата}. Делались работы"
Новые/изменённые блоки:
//SCR ГГГГ ММ ДД↓
Код доработки
//SCR ГГГГ ММ ДД↑
Дата текущая, исторические маркеры сохранять, неизменённые даты не обновлять, лишние вложенные маркеры не создавать.
Не нарушать синтаксис и связь директив с методом. Дословные цитаты не менять и не маркировать.
В XML комментарии только внутри текста BSL-обработчика с нужным экранированием, не в служебных узлах/атрибутах.
Запрос оформлять по структуре; встроенный строковый литерал сохранять корректным.
